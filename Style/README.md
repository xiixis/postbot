## Что показали замеры

Норма доли акцента — 4–6% площади кадра: меньше 2% не видно с расстояния ленты, больше 8% перестаёт быть акцентом. Вот как она разложилась по кадрам у всех пятнадцати стилей:

| кадр | среднее | самый скупой | самый щедрый |
|---|---|---|---|
| обложка | 0.4% | каталог 0.11% | пособие 3.42% |
| список | 0.4% | каталог 0.09% | брутальный 0.85% |
| правка | 7.7% | минимал 2.27% | заметка 16.4% |
| финал | 7.6% | каталог 0.31% | минимал 9.25% |

Видно две вещи, которых по одному стилю не заметишь. Обложки почти лишены акцента — доли процента вместо четырёх: лайм там живёт тонкой линейкой и подписью «листайте». А кадр «правка» у части стилей перебирает вдвое: подсветка ключевых слов занимает площадь целой плашки. Это не поломка, кадры выпускаются и принимаются — но если обложки станут цеплять хуже, смотреть надо сюда.

## Как пересобрать

```sh
python3 tools_style.py            # всё: отрисовка, замеры, паспорта
python3 tools_style.py --мерить   # только замеры и схожесть
python3 tools_style.py --собрать  # только паспорта и README
```

Отрисовка идёт через прогретый браузер и занимает около половины минуты на все пятнадцать. Источник правды — `card.ДИЗАЙНЫ` и `форматы.py`: правим там, потом пересобираем.
