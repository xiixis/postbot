# Фото-Карусель, стиль «подборка GitHub» (терминал с $)

Тёмный кадр 1620×2160: призрачный вывод git, огромный `$`, картинка проекта в окне
со свечением, звёзды, лаймовая ссылка `github.com/…`, текст JetBrains Mono, знак и
лаймовая полоса. Картинка у каждого проекта своя — правило Фото-Карусели.

Посты: `посты/лето.json` (14.09, «10 GitHub-проектов этого лета», @git_code),
`посты/замены.json` (15.09, «9 GitHub-репозиториев вместо платных ИИ», @mike.mozg;
паспорта этого референса в репозитории нет; `референс/` — кадры поста @git_code).

## Собрать пост

1. Картинки проектов в `repo/` (или подпапку): превью репозитория (`og:image` со
   страницы GitHub — «свой», если адрес repository-images…), скриншоты из README,
   или снимок сайта `node ../подборка-сайтов/снять.mjs`. Смотреть глазами: у многих
   превью — один логотип, продукта не видно.
2. Звёзды свежие из api.github.com; архивные репозитории (`archived: true`) не брать.
3. Файл `посты/<слаг>.json`:
   - `обложка.сцена`: `терминал` (окно с командой и заголовок) или `цифра`
     (огромная цифра Oswald, заголовок Manrope, подиум с котом);
   - `проекты[]`: `repo`, `картинка`, `звёзды`, `текст`; с полями `заменяет` и
     `нюанс` кадр рисуется со строками «→ заменяет X» и «# нюанс: …»; `обрезка` —
     прямоугольник в пикселях исходной картинки;
   - `финал`: окно с командой, `строки_заголовка`, `подзаголовок`, по желанию `кот`;
   - `папка`, `подпись`.
4. `pb py Style/подборка-github/github.py Style/подборка-github/посты/<слаг>.json` — кадры в
   `кадры/<слаг>/`, JPG 1080×1440 и подпись на стол. С номерами (`… 01 11`) только они.

Обложку и финал каждый раз делать новыми — одинаковые кадры TikTok считает
повтором.

Референс стиля — `референс/` (@git_code, 114 тыс. показов, 8,7 тыс. сохранений); обложка
«цифра» разобрана по другому посту — `референс-обложки-цифра/` (ссылка на
`../../референсы/mike.mozg-7685035028379634945`, там же паспорт).

## Папка стиля

- `ДИЗАЙН.md` — этот файл: паспорт стиля и порядок сборки поста;
- `референс/` — кадры и `пост.json` чужого поста, по которому стиль разобран;
- `образец/<пост>/` — принятые кадры наших постов: ими проверять, что правка кода не сломала вид;
- `посты/*.json` — содержимое постов; `кадры/<пост>/` — последняя отрисовка;
- общее для всех стилей (лайм, шрифты, знак с полосой, кот, замер запаса) — `../стиль.py`,
  своё у стиля — только палитра и вёрстка в рисовальщике.

Проверка после правки кода: перерисовать пост с номерами кадров (без номеров перезапишется
папка на столе) и сравнить с `образец/<пост>/` — разница до ~1–2 из 255 (зерно и JPEG).
Замер печатает `тесно` и `край` — кадр годен, когда оба пусты (запас 40 px, край 100 px).
