## Собрать пост

1. Значки в `значки/` — с сайтов самих сервисов (`<link rel=icon>`, apple-touch-icon,
   favicon.svg) или Simple Icons. Сайт за проверкой Vercel (devin.ai) отдаёт curl-у
   страницу-заглушку вместо картинки: `node значок-браузером.mjs <страница> <адрес
   картинки> <файл>`. Смотреть листом глазами: Simple Icons у Zapier — надпись, у OpenAI
   чёрный знак (нужна `инверсия`).
2. Цены сверять с их страницами цен в день поста; переименования проверять
   (Windsurf → Devin Desktop со 2 июня 2026).
3. Файл `посты/<слаг>.json`: `обложка`, `пары[]` (у стороны: `имя`, `строка`, `значок`,
   `плитка` — `во весь` для квадратного значка с фоном, `тёмная`/`светлая` для знака на
   плитке, `размер` в % плитки, `инверсия`, `свет` — цвет отсвета; у бесплатной ещё
   `как`: `сразу`/`сам`), `почему`, `финал`, `папка`, `подпись`.
4. `~/4xSoft/yt-searcher/.venv/bin/python3 рисовать.py посты/<слаг>.json` — кадры в
   `кадры/<слаг>/`, JPG 1080×1440 и подпись на стол. С номерами (`… 01 07`) только они.
   Лист для глаз: `python3 лист.py кадры/<слаг> <куда.png>`.

## Замер запаса (слово владельца 15.09.2026)

Ничто важное не стоит впритык к другому важному. Замер печатает:
- `тесно` — пары блоков `data-блок` ближе **40 px** (≈10 точек на экране телефона);
- `край` — текст ближе **100 px** к краю кадра;
- `ужато` — строки, ужатые подгонкой под свою ширину.

Кадр годен, когда `тесно` и `край` пустые. Рамка текста — по строкам (Range по текстовым
узлам), у блока с `overflow:hidden` — он сам, кот обрезан по видимым пикселям.
Строки внутри одного блока (две строки заголовка) замер не сравнивает: соприкосновение
букв между строками (бревис «Й» под строкой выше) ловится только глазами.

Обложку и финал следующего поста в этом стиле делать другими — TikTok считает
одинаковые кадры повтором.

## Папка стиля

- `ДИЗАЙН.md` — этот файл: паспорт стиля и порядок сборки поста;
- `референс/` — кадры и `пост.json` чужого поста, по которому стиль разобран;
- `образец/<пост>/` — принятые кадры наших постов: ими проверять, что правка кода не сломала вид;
- `посты/*.json` — содержимое постов; `кадры/<пост>/` — последняя отрисовка;
- общее для всех стилей (лайм, шрифты, знак с полосой, кот, замер запаса) — `../стиль.py`,
  своё у стиля — только палитра и вёрстка в рисовальщике.

Проверка после правки кода: перерисовать пост с номерами кадров (без номеров перезапишется
папка на столе) и сравнить с `образец/<пост>/` — разница до ~1–2 из 255 (зерно и JPEG).
Замер печатает `тесно` и `край` — кадр годен, когда оба пусты (запас 40 px, край 100 px).

## Вариация «фразы» (17.09.2026)

`фразы.py посты/фразы.json` — «так не пиши | пиши вот так»: шапка «тонко + крупно лаймом» поменьше,
под ней сетка из двух колонок по 9 плашек, ряды выровнены (колонка «нет» 40%, зачёркнута красным
`#FF5A4E`, колонка «да» с лаймовой меткой), `нумерация: true` — номера пар. Кадр «почему» — общий из
`рисовать.py`, финал свой (кот справа, призыв столбцом, без телефона). Три обложки: кот с перечёркнутым
облачком, гигантское число с маркером, сравнение «так пишут все / а надо так» (`обложка-2`, `обложка-3`
на столе рядом с кадрами). Первый пост — рерайт @ythemark «Слова, которые нельзя писать в ChatGPT».

**Холст перед столом (слово владельца 17.09.2026).** Пост не уходит на стол, пока владелец не
посмотрел и не поправил его на холсте: `python3 холст.py посты/<пост>.json` → выложить страницу
`холсты/<пост>/<латиницей>.html` одним вызовом Artifact (`contract 0.1.31`, `self` и `downloads`) →
«готово» → `Artifact read_file index.html` → `python3 ../выпуск.py пары/посты/<пост>.json <index.html>`.
`фразы.py` без номеров кадров сразу кладёт на стол — так выпускать нельзя, только с номерами для проверки.

**Приёмы из remocn (MIT, `remocn.dev`), перенесённые в вёрстку 17.09.2026** — библиотека под Remotion,
но сами приёмы это SVG и CSS, поэтому Remotion в конвейер каруселей не тянем:
- `штрих()` — зачёркивание от руки (Scribble Circle): лента переменной толщины по профилю нажима,
  рваный край. Идёт **фоном строчного элемента** с `box-decoration-break: clone` — слой поверх ячейки
  у строки в два ряда проходил между рядами.
- `обводка()` — то же кольцом вокруг слова; `стрелка()` — дуга с наконечником (Ink Arrow).
  SVG обязательно внутри блока с заданными краями и `width/height:100%`: без явных размеров браузер
  берёт пропорции из `viewBox`, и кольцо раздувается втрое.
- `.окно` — стеклянное окно промпта (Glass Code Block): `backdrop-filter: blur`, три точки, текст JetBrains.
Не взято: анимации текста, переходы, эффекты движения — для статичного кадра они бессмысленны.
