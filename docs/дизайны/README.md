| [манифест](манифест/ПАСПОРТ.md) | да | узкие заглавные во всю ширину, линейка слева, без акцента |
| [атмосфера](атмосфера/ПАСПОРТ.md) | да | свечение сверху, пустота, заголовок прижат к низу |
| [каталог](каталог/ПАСПОРТ.md) | да | светлый кадр, пилюли-теги и карточки с номером и долей |
