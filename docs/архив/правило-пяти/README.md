# Правило пяти постов — в архиве с 21.09.2026

Между двумя постами на одну тему должно выйти пять постов на другие темы.
Не подсказка модели списком прошлых тем, а жёсткий счёт по позиции.

**Почему здесь, а не в работе.** Код написан 10.09.2026 и покрыт тестами, но
ни разу не подключался: `темы.py` никто не вызывал, таблицы `themes` и
`theme_usage` пустые. Год спустя это выглядело бы живой защитой от повторов,
которой на самом деле нет. Решение владельца 21.09.2026 — в архив, не
выбрасывать: замысел верный, просто руки не дошли.

**Что осталось в рабочем коде.** Функции базы `db.уже_писали`,
`db.отметить_тему`, `db.справочник_тем`, `db.применения_тем`,
`db.позиция_следующего` и обе таблицы — они безвредны и понадобятся, если
правило будут доделывать. Неподключённой была только эта пара файлов.

**Что нужно, чтобы оживить.** Одна правка: перед выбором темы в `core.эскиз`
спросить `темы.доступна(...)`, а после выхода поста позвать `db.отметить_тему`.
Задача висит неотмеченной в `docs/superpowers/specs/2026-09-15-конвейер-карусели-design.md`.

**Пока правило не работает**, тему для нового поста сверяют руками:
`python3 -c 'import db; print("\n".join(db.о_чём_писали(15)))'` и папки
`~/Desktop/Посты`.
