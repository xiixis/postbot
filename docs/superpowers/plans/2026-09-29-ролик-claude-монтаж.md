# Ролик «Этот ролик никто не монтировал»: план

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement
> this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** вертикальный ролик 15 секунд со вшитой музыкой на столе владельца.

**Architecture:** один непрерывный план в Remotion. Слои лежат друг на друге и живут каждый
в своём отрезке времени; моменты берутся из одной сетки тактов в `tokens.ts`.

**Tech Stack:** Remotion 4.0.482, React 18, ffmpeg, numpy; Gemini и Lyria через Vertex.

Спека: `docs/superpowers/specs/2026-09-29-ролик-claude-монтаж-design.md`.

## Global Constraints

- 1080×1920, 30 кадров в секунду, 450 кадров.
- Цвета: графит `#12130F`, крем `#F1F2EA`, лайм `#C7E24B`, терракотовый `#D97757` только для слова Claude.
- Текст не правее 900 px и не ниже 1500 px, от левого края 80 px.
- Состояние держится 72 кадра; появление 18–26 кадров, уход 10–14.
- Одна кривая появления на весь ролик: `cubic-bezier(0.16, 1, 0.3, 1)`. Пружин нет.
- В тексте кадра нет тире и нет упоминания языка.
- Имена файлов кода и ассетов латиницей; русские — текст кадра и комментарии.
- Рендер один, фоном, после `sysctl vm.swapusage`.
- Публикация и черновики — только по слову владельца.
