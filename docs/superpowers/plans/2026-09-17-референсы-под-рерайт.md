# База референсов под рерайт — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** ссылки из темы «Под рерайт» группы «Полезное» сами ложатся в таблицу `references`, а Claude берёт оттуда референс и отмечает, в какой пост он ушёл.

**Architecture:** таблица и запросы — в `db.py` (SQLite на маке, Postgres в Supabase). Чистая логика сбора (приведение ссылок, извлечение, запись, курсор) — новый модуль `референсы.py`, чтение Telegram — функция в `userbot.py`, которую `референсы.сверить` получает параметром (тесты подставляют дублёра). Бот зовёт `сверить()` в главном цикле раз в 5 минут; Claude работает через `tools_референсы.py`.

**Tech Stack:** Python 3.12 (`/Users/xiix/4xSoft/yt-searcher/.venv/bin/python3`), sqlite3/psycopg, Telethon, unittest.

Спека: `docs/superpowers/specs/2026-09-17-референсы-под-рерайт-design.md`.

## Global Constraints

- Группа `-1004462031298`, тема `14`; другие темы не читать, в группу ничего не писать.
- Статусы ровно: `новая`, `в работе`, `использована`, `отброшена`.
- Курсор — настройка `референсы.курсор`; двигается и сообщениями без ссылок; при ошибке чтения не двигается.
- Сбор не чаще раза в 5 минут; ошибка сети печатается и не роняет бота.
- `userbot.вошли()` ложно — сбор тихо выключен.
- У Instagram и TikTok (полный адрес) отрезаются параметры и якорь; `vt.tiktok.com/…` не меняется.
- Тесты — unittest на временной SQLite, без сети. Запуск: `python3 -m unittest tests.test_референсы -v` из корня постбота.
- Облако (`vercel/`) не пересобирать и не пушить: push в master выкатывает Vercel.

Ловится то, что ломается тихо: одна ссылка, скинутая дважды, даёт две строки;

СТАТУСЫ_РЕФЕРЕНСА = ("новая", "в работе", "использована", "отброшена")


def добавить_референс(url: str, площадка: str, tg_message_id: int, добавлена: str) -> bool:
    """Кладёт ссылку в очередь. False — такая уже есть: повтор молча пропускается."""
    подготовить()
    with соединение() as c:
        было = c.execute('SELECT 1 FROM "references" WHERE url=?', (url,)).fetchone()
        if было:
            return False
        c.execute('INSERT INTO "references" (url, площадка, tg_message_id, добавлена)'
                  " VALUES (?,?,?,?) ON CONFLICT(url) DO NOTHING",
                  (url, площадка, tg_message_id, добавлена))
    return True


def референсы(статус: str | None = "новая") -> list:
    """Очередь референсов, старые сверху. `None` — все статусы."""
    подготовить()
    with соединение() as c:
        if статус is None:
            return c.execute('SELECT * FROM "references" ORDER BY tg_message_id, id').fetchall()
        return c.execute('SELECT * FROM "references" WHERE статус=? ORDER BY tg_message_id, id',
                         (статус,)).fetchall()


def отметить_референс(ид: int, статус: str, post_id: int | None = None,
                      заметка: str | None = None) -> None:
    if статус not in СТАТУСЫ_РЕФЕРЕНСА:
        raise ValueError(f"статус «{статус}» не из {СТАТУСЫ_РЕФЕРЕНСА}")
    подготовить()
    with соединение() as c:
        c.execute('UPDATE "references" SET статус=?, post_id=COALESCE(?, post_id),'
                  " заметка=COALESCE(?, заметка) WHERE id=?", (статус, post_id, заметка, ид))


def взять_референс(ид: int | None = None):
    """Референс в работу: названный номер или самая старая новая. None — брать нечего."""
    if ид is None:
        очередь = референсы("новая")
        if not очередь:
            return None
        ид = очередь[0]["id"]
    отметить_референс(ид, "в работе")
    with соединение() as c:
        return c.execute('SELECT * FROM "references" WHERE id=?', (ид,)).fetchone()
```

# -*- coding: utf-8 -*-
"""Референсы под рерайт: ссылки из темы «Под рерайт» группы «Полезное» в базу.

Владелец кидает ссылки на чужие посты в эту тему, а Claude по слову «возьми
референс из базы» берёт оттуда и не берёт одну и ту же дважды. Здесь только
сбор: скачивание и разбор — потом, поверх той же таблицы.

Читает аккаунт владельца, а не бот: история темы хранится без срока, поэтому
всё, что пришло, пока мак спал, добирается следующим кругом, а бота не надо
делать админом группы.
"""
import re
import time
from urllib.parse import urlsplit, urlunsplit

import db

ГРУППА = -1004462031298          # «Полезное», группа с темами
ТЕМА = 14                        # «Под рерайт»; другие темы не читаем
КУРСОР = "референсы.курсор"      # номер последнего прочитанного сообщения темы
КОГДА = "референсы.когда"
РАЗ_В = 5 * 60
_АДРЕС = re.compile(r"https?://[^\s<>\"']+")


def привести(url: str) -> str:
    """Один пост — одна строка: у Instagram и TikTok отрезаются параметры.

    Один и тот же пост, скинутый с разных кадров, отличается только
    `?img_index=…&stkn=…`. Короткие vt.tiktok.com не трогаем: раскрыть их
    значит ходить в сеть, а это уже не «только запись».
    """
    url = url.strip()
    ч = urlsplit(url)
    хост = ч.netloc.lower()
    if хост.endswith("instagram.com") or хост in ("tiktok.com", "www.tiktok.com"):
        return urlunsplit((ч.scheme, хост, ч.path, "", ""))
    return url


def площадка(url: str) -> str:
    хост = urlsplit(url).netloc.lower()
    if хост.endswith("instagram.com"):
        return "instagram"
    if хост.endswith("tiktok.com"):
        return "tiktok"
    return "другое"


def ссылки(текст: str, адреса=()) -> list[str]:
    """Адреса из сущностей сообщения и из самого текста, без повторов, по порядку."""
    итог = []
    for а in [*адреса, *_АДРЕС.findall(текст or "")]:
        а = а.rstrip(").,;")
        if а not in итог:
            итог.append(а)
    return итог


def записать(сообщения: list[dict]) -> int:
    """Кладёт ссылки сообщений в базу и двигает курсор. Возвращает число новых."""
    новых, курсор = 0, db.настройка(КУРСОР, 0)
    for м in sorted(сообщения, key=lambda м: м["id"]):
        for а in ссылки(м.get("текст", ""), м.get("адреса", [])):
            а = привести(а)
            новых += db.добавить_референс(а, площадка(а), м["id"], м["дата"])
        курсор = max(курсор, м["id"])
    db.запомнить(КУРСОР, курсор)
    return новых


def сверить(читать=None) -> int:
    """Дочитывает тему после курсора. Ошибка чтения летит наружу, курсор не трогается."""
    if читать is None:
        import userbot
        if not userbot.вошли():
            return 0
        читать = lambda после: userbot.сообщения_темы(ГРУППА, ТЕМА, после)  # noqa: E731
    # Время сверки — до чтения: без сети бот иначе стучался бы в Telegram на каждом
    # круге цикла (раз в полминуты). Курсор при ошибке всё равно стоит.
    db.запомнить(КОГДА, time.time())
    сообщения = читать(db.настройка(КУРСОР, 0))
    return записать(сообщения)


def пора() -> bool:
    return time.time() - float(db.настройка(КОГДА, 0) or 0) > РАЗ_В
```

async def _сообщения_темы(группа: int, тема: int, после: int) -> list[dict]:
    async with _клиент() as клиент:
        итог = []
        async for м in клиент.iter_messages(группа, reply_to=тема, min_id=после, reverse=True):
            адреса = [getattr(с, "url", None) or т
                      for с, т in (м.get_entities_text() or [])
                      if getattr(с, "url", None) or type(с).__name__ == "MessageEntityUrl"]
            итог.append({"id": м.id, "дата": м.date.isoformat(timespec="seconds"),
                         "текст": м.text or "", "адреса": адреса})
        return итог


def сообщения_темы(группа: int, тема: int, после: int) -> list[dict]:
    """Сообщения одной темы группы новее номера `после`, старые первыми.

    Только чтение. Боту Telegram историю группы не отдаёт, аккаунт видит её как человек.
    """
    return asyncio.run(_сообщения_темы(группа, тема, после))

```python
# -*- coding: utf-8 -*-
"""Референсы под рерайт из командной строки.

    python3 tools_референсы.py список [статус|все]
    python3 tools_референсы.py взять [номер]
    python3 tools_референсы.py готово <номер> [пост] [заметка]
    python3 tools_референсы.py отбросить <номер> [причина]
    python3 tools_референсы.py сверить

`сверить` читает тему копией сессии: живой бот держит файл сессии, и два
процесса на одном файле ловят «database is locked».
"""
import shutil
import sys
import tempfile
from pathlib import Path

import db
import референсы


def _строка(р) -> str:
    пост = f" → пост {р['post_id']}" if р["post_id"] else ""
    заметка = f" · {р['заметка']}" if р["заметка"] else ""
    return f"{р['id']:>3}  {р['статус']:<12} {р['добавлена'][:10]}  {р['url']}{пост}{заметка}"


def main(арг: list[str]) -> None:
    команда = арг[0] if арг else "список"
    if команда == "список":
        статус = арг[1] if len(арг) > 1 else "новая"
        ряды = db.референсы(None if статус == "все" else статус)
        print("\n".join(_строка(р) for р in ряды) or "пусто")
    elif команда == "взять":
        р = db.взять_референс(int(арг[1]) if len(арг) > 1 else None)
        print(_строка(р) if р else "новых нет")
    elif команда == "готово":
        db.отметить_референс(int(арг[1]), "использована",
                             post_id=int(арг[2]) if len(арг) > 2 and арг[2].isdigit() else None,
                             заметка=" ".join(арг[3:]) or None)
        print("отмечено")
    elif команда == "отбросить":
        db.отметить_референс(int(арг[1]), "отброшена", заметка=" ".join(арг[2:]) or None)
        print("отброшено")
    elif команда == "сверить":
        import userbot
        with tempfile.TemporaryDirectory() as врем:
            копия = Path(врем) / "аккаунт"
            shutil.copy(f"{userbot.СЕССИЯ}.session", f"{копия}.session")
            userbot.СЕССИЯ = копия
            print("новых:", референсы.сверить())
    else:
        sys.exit(__doc__)


if __name__ == "__main__":
    main(sys.argv[1:])
```
