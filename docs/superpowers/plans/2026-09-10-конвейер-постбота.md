# Конвейер постбота: план → эскиз → рендер

> **Исполнителю:** брать задачи по порядку. Шаги отмечены `- [ ]`. Тесты
> гоняются `python3 -m unittest discover -s tests -q` из корня `postbot`.
> Базовая линия на 2026-09-10: 157 тестов, OK.

**Цель.** Убрать повторные прогоны и повторяющиеся темы: показывать текст до
рисования, вести журнал тем с запретом на возврат раньше пятого поста и мерить
готовые кадры.

**Устройство.** Три правки не связаны между собой и ставятся по одной.
Журнал тем живёт в базе рядом с постами. Эскиз — новый статус поста, а не
новый модуль. Замер кадров переиспользует готовый разбор из
`~/4xSoft/исследование-тикток-карусели/числа.py`.

**Чем писано.** Python 3.12, sqlite и postgres через `db._Связь`, тесты на
`unittest`, модель через Claude Code CLI (`агент.по_форме`).

## Общие ограничения

- Тема не выдаётся, пока между ней и прошлым применением меньше **пяти**
  чужих постов.
- Темы берутся только из справочника; конвейер новых не придумывает.
- Имена собственные из чужой базы не переписываются: `Nano Banana`,
  `Higgsfield`, `HeyGen`, `Nextcloud` — как в источнике.
- Рисование не запускается, пока текст не прошёл стадию эскиза.
- База у владельца живая: новые колонки только через `db.ДОБАВКИ`, таблицы
  только через `CREATE TABLE IF NOT EXISTS`.

- [ ] **Шаг 3. Написать модуль**

```python
# -*- coding: utf-8 -*-
"""Очередь тем и правило пяти постов.

Между двумя применениями одной темы обязаны лежать пять чужих постов.
Разрыв считается по позиции — сквозному номеру поста, а не по дате: дата
скачет от расписания, а порядок выхода — нет.
"""

РАЗРЫВ = 5


def доступна(theme_id: int, позиция: int, применения: dict) -> bool:
    """Прошло ли пять чужих постов с прошлого раза."""
    было = применения.get(theme_id) or []
    if not было:
        return True
    return позиция - max(было) > РАЗРЫВ
```

def свободные(позиция: int, справочник: list, применения: dict) -> list:
