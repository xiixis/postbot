## Беда

7 обложек из 10 живых каруселей (91–102) рисуются без кота: `слайд_обложка` ставит кота
по CSS в одно место и одного роста (`кот_высота`, низ `поле_низ - 40`), кегль заголовка
подобран без учёта кота, заголовок доходит до кота — проверка находит «кот накрывает
текст» и кот убирается целиком. Кадры середины эту задачу решают: рост кота считается
от настоящего низа текста (`страница_вида`, `_рост_в_колонке`), с запасом `_запас_px`.

## Что сделать

1. **Тест сначала** — `tests/test_обложка_с_котом.py`:
   - без Chrome: новая функция `card._рост_кота_обложки(тексты, ш, в, низ, доля,
     предел, по_центру, поле)` возвращает наибольший рост `≤ предел`, при котором
     прямоугольник кота (по центру — `ш/2 ± рост·доля/2`; иначе справа от `ш - поле`,
     как `_рост_в_колонке` с `слева=False`) отстоит от каждого прямоугольника текста не
     меньше чем на `card._запас_px(ш)` по `card._зазор`; шаг 16 px; меньше `МИН_КОТ` → 0.
     Случаи: текст высоко — рост = предел; текст до середины — рост меньше предела и
     зазор ≥ запаса; текст до низа — 0.
   - с Chrome (`@unittest.skipUnless(config.хром(), …)`): `card.слайд_обложка` с
     длинным заголовком в «3к4» и позой `assets/mascot/позы/ukazyvaet.png`, `_снять`
     подменён записью (как в `tests/test_вид_на_всех_связках.py`): в записанной
     странице есть кот (`class="кот"`), и `card.проверить_композицию` по её замеру не
     содержит бед со словами «кот» и «впритык».
   Убедиться, что тест падает до правки.
2. **`card._обложка_страница`**: параметр `высота_кота: int = 0` — если задан, в стили
   идёт он вместо `д["кот_высота"]` (класс `.кот img` берёт `{кот_высота}`).
3. **`card.слайд_обложка`**: если есть кот — замерить страницу без кота; тексты =
   `замер["текст"] + замер["строки"]`; `низ = в - д["низ_кота"]` из `_обложка_страница`
   (сейчас `max(поле_низ - 40, 0)` — вынести в одно место, не дублировать);
   `доля = _доля_позы(поза)`; `рост = _рост_кота_обложки(...)` с `предел=д["кот_высота"]`.
   Рост ≥ `МИН_КОТ` → собрать с котом этого роста и проверить композицию как сейчас;
   беды → без кота, как сейчас. Кегль заголовка не трогать.
4. Комментарии в стиле файла: почему, со ссылкой на Д-17.
