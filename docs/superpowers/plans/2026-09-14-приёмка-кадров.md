# Приёмка кадров: брак не уходит молча

> **Исполнителю:** обязательный скил — `executing-plans` (или
> `subagent-driven-development`). Задачи брать по порядку, шаги отмечены `- [ ]`.
> Тесты гоняются из корня копии интерпретатором бота:
> `/Users/xiix/4xSoft/yt-searcher/.venv/bin/python3 -m unittest discover -s tests -q`.
> Базовая линия на 14 сентября 2026: **351 тест, OK, 14,4 с**.

**Цель.** Перенять из инструмента знакомого (`4xSoft/html-instagram-carousel`)
то, чего у постбота нет: проверка кадра выносит вердикт «годен / брак», брак
не уезжает сам ни в папку на столе, ни в план, вся карусель видна одним листом,
не хватающие проверки (обрезка по высоте, битая картинка, битый шрифт, ошибки
страницы, размер снимка) появляются, а переполнение текста сначала лечится
сокращением текста и только потом шрифтом.

**Устройство.**
- Новый модуль `приёмка.py`: журнал одной отрисовки в нити. Рисовальщик пишет
  туда брак и замечания по кадру.
- **Брак ставит одна точка**, `card._снять`: снимок готов, страница меряется ещё
  раз (почти всегда из кэша) и итог проверок идёт в журнал. Так обложка,
  середина и финал судятся одинаково, какой бы дорогой ни шли.
- Замечания (кот убран, шрифт ужат, строки рвано, плотность) ставятся там, где
  происходят.
- `carousel.нарисовать` отмечает номер кадра, `core` забирает отчёт в карточку
  поста (`поля["приёмка"]`). По отчёту `выгрузка.сразу` не собирает папку,
  `конвейер` не ставит пост в план и докладывает владельцу листом кадров,
  `придирки` показывают брак под черновиком.
- При `сокращать=True` (полная генерация) кадр с браком раскладки или ужатым
  глубже 0,78 шрифтом отправляется модели сократить и рисуется заново один раз.

**Чем писано.** Python 3.12, `unittest`, Chrome по CDP (`браузер.py`), Pillow
только внутри функций, модель через `агент.по_форме`.

```python
# -*- coding: utf-8 -*-
"""Приёмка кадров: что осталось не так, когда рисовальщик сделал всё, что мог.

Проверки кадра были и раньше, но только печатали строчку в лог и отдавали кадр
дальше. Строчку никто не читает: автопилот рисует ночью, а владелец видит уже
готовые картинки. Так кадр с обрезанным словом доезжал до папки на столе.

Здесь журнал одной отрисовки. Рисовальщик отмечает в нём брак и замечания по
кадру, а тот, кто рисовал карусель, забирает итог и решает, пускать ли её
дальше. Приём взят у html-instagram-carousel: проверка там не советует, а
выносит вердикт «годен / брак», и брак дальше сам не идёт.

Брак — то, что на картинке видно как поломку: текст за краем, слово цвета фона,
не загрузилась картинка. Замечание — то, о чём стоит знать, но что кадр не
портит: кот убран, шрифт ужат, строки легли неровно.

Журнал живёт в нити. Без начатого журнала отметки молча пропадают: так рисуют
афиша, сторис и подготовка под другую площадку, им приёмка не нужна.
"""

import threading

_своё = threading.local()

# Беды окружения, а не раскладки: файл, шрифт, браузер. Текст их не лечит, и
# сокращать ради них слайд бессмысленно.
СТРАНИЦА = "страница: "


def начать() -> None:
    _своё.журнал = {}
    _своё.номер = None


def идёт() -> bool:
    return getattr(_своё, "журнал", None) is not None


def кадр(номер: int, вид: str) -> None:
    """Дальнейшие отметки относятся к этому кадру. Повтор номера начинает его заново."""
    if not идёт():
        return
    _своё.журнал[номер] = {"номер": номер, "вид": вид, "брак": [],
                           "замечания": [], "ужато": 1.0}
    _своё.номер = номер


def _запись() -> dict | None:
    if not идёт():
        return None
    return _своё.журнал.get(getattr(_своё, "номер", None))


def брак(*беды: str) -> None:
    запись = _запись()
    if запись is None:
        return
    for беда in беды:
        if беда and беда not in запись["брак"]:
            запись["брак"].append(беда)


def замечание(текст: str) -> None:
    запись = _запись()
    if запись is not None and текст and текст not in запись["замечания"]:
        запись["замечания"].append(текст)


def ужато(доля: float) -> None:
    запись = _запись()
    if запись is not None:
        запись["ужато"] = round(min(запись["ужато"], доля), 2)


def текущий() -> dict:
    """Копия записи текущего кадра. Пусто, если журнала нет."""
    запись = _запись()
    if not запись:
        return {}
    return {**запись, "брак": list(запись["брак"]),
            "замечания": list(запись["замечания"])}


def _отчёт(кадры: list) -> dict:
    return {"годен": not any(к["брак"] for к in кадры), "кадры": кадры}


def итог() -> dict:
    """Забирает журнал и закрывает его. Пусто, если журнал не начинали."""
    журнал = getattr(_своё, "журнал", None)
    _своё.журнал, _своё.номер = None, None
    if журнал is None:
        return {}
    return _отчёт([журнал[н] for н in sorted(журнал)])


def слить(было: dict | None, свежие: dict | None) -> dict:
    """Отчёт после перерисовки части кадров: свежие записи заменяют прежние."""
    по_номеру = {к["номер"]: к for к in (было or {}).get("кадры", [])}
    по_номеру.update({к["номер"]: к for к in (свежие or {}).get("кадры", [])})
    return _отчёт([по_номеру[н] for н in sorted(по_номеру)])


def годен(отчёт: dict | None) -> bool:
    """Нет отчёта — пост рисован до приёмки, судить его нечем."""
    return (отчёт or {}).get("годен", True)


def бракованные(отчёт: dict | None) -> list[int]:
    return [к["номер"] for к in (отчёт or {}).get("кадры", []) if к["брак"]]


def строкой(отчёт: dict | None) -> str:
    """«№4: текст за краем; №7: …». Пусто, если брака нет."""
    return "; ".join(f"№{к['номер']}: {', '.join(к['брак'])}"
                     for к in (отчёт or {}).get("кадры", []) if к["брак"])


def лечится_текстом(запись: dict, порог: float = 0.78) -> bool:
    """Поможет ли сократить текст: брак от раскладки или шрифт ужат глубоко."""
    if not запись:
        return False
    раскладка = [б for б in запись.get("брак", []) if not б.startswith(СТРАНИЦА)]
    return bool(раскладка) or запись.get("ужато", 1.0) < порог
```

    """Ширина и высота из заголовка PNG, без Pillow: card едет в облако."""
    try:
        with open(путь, "rb") as f:
            голова = f.read(24)
    except OSError:
        return None
    if len(голова) < 24 or голова[1:4] != b"PNG":
        return None
    return int.from_bytes(голова[16:20], "big"), int.from_bytes(голова[20:24], "big")

# -*- coding: utf-8 -*-
"""Лист кадров: вся карусель одной картинкой.

Приём из html-instagram-carousel: после отрисовки там собирается contact sheet,
и ритм серии, повторы вёрсток и кривой кадр видны одним взглядом. Десять
отдельных картинок так не смотрятся — каждая по отдельности выглядит сносно.

Собирается Pillow, без браузера: на маке 16 ГБ, и поднимать Chrome ради
склейки готовых PNG незачем. Подписи — только номера: встроенный шрифт Pillow
кириллицы не знает, а брак и так виден по рамке.
"""

import secrets
from pathlib import Path

КОЛОНОК = 5
ШИРИНА = 216          # превью кадра; десять кадров 3:4 — лист около 1200×690
ЗАЗОР = 16
ПОДПИСЬ = 32
ФОН = (18, 19, 15)
ТЕКСТ = (241, 243, 234)
БРАК = (226, 112, 58)  # config.РЖАВЫЙ


def собрать(файлы: list, куда: Path | None = None, брак=()) -> Path | None:
    """Склеивает кадры сеткой. Номера кадров из «брак» обводятся ржавым."""
    from PIL import Image, ImageDraw, ImageFont

    кадры = [Path(ф) for ф in файлы if ф and Path(ф).exists()]
    if not кадры:
        return None
    превью = []
    for ф in кадры:
        with Image.open(ф) as к:
            к = к.convert("RGB")
            превью.append(к.resize((ШИРИНА, round(к.height * ШИРИНА / к.width)),
                                   Image.LANCZOS))
    колонок = min(КОЛОНОК, len(превью))
    рядов = -(-len(превью) // колонок)
    клетка = max(п.height for п in превью) + ПОДПИСЬ
