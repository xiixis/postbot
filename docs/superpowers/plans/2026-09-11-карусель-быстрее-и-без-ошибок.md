# Карусель: быстрее и без ошибок на кадрах

> **Исполнителю:** обязательный скил — `subagent-driven-development` (лучше) или
> `executing-plans`. Задачи брать по порядку, шаги отмечены `- [ ]`. Тесты
> гоняются `python3 -m unittest discover -s tests -q` из корня копии, тем
> интерпретатором, которым живёт бот:
> `/Users/xiix/4xSoft/yt-searcher/.venv/bin/python3`.
> Базовая линия на 11 сентября 2026: **215 тестов, OK, 4,6 с**.

**Цель.** Снизить число ошибок на кадрах карусели и время её сборки. Сейчас на 7
заказов приходится 11 ручных перерисовок, а отрисовка 10 кадров идёт 64 с,
потому что Chrome запускается 59 раз.

**Устройство.** Сначала страховка и ошибки. Эталонные страницы поста 96
становятся тестами, а в замер внутри страницы (`card.ЗАМЕР`) добавляются две
проверки: «текст сливается с фоном» и «слово порвано посреди». Их находки
становятся бедами `card.проверить_композицию`, и существующий цикл ужатия
реагирует на них сам. Попутно чинится 98/07. Потом скорость: кэш повторных
замеров, движок chrome-headless-shell, один прогретый браузер по протоколу
отладки (`браузер.py`, при любом сбое откат на командную строку) и загрузка в
облако в четыре потока. Хуманайзер получает усердие medium сразу, а в один
проход со сценарием переходит только после опыта и слова владельца.

**Чем писано.** Python 3.12, тесты на `unittest`. Chrome — через командную
строку и CDP (`websockets` 17, синхронный клиент `websockets.sync`). Pillow и
numpy — только в тестах. Модель — через Claude Code CLI (`агент.текстом`,
`агент.по_форме`).

## Общие ограничения

- **Новых зависимостей не ставить.** `websockets` уже есть в окружении бота; его
  только вписать в `requirements.txt`.
- **`card.py` и `storage.py` едут в облачную копию** (`tools_vercel.py`, список
  `МОДУЛИ`). В них нельзя импортировать сверху ни `браузер`, ни `websockets`, ни
  numpy. `браузер` импортируется внутри функции, `ImportError` означает старый
  путь. `браузер.py` в `МОДУЛИ` не добавлять.
- **Пороги не трогать без слова владельца:** заход текста на призыв 45% строки,
  срез кота краем на треть.
- **Качество не снижать:** размер кадра, масштаб 1,5 и нынешние проверки
  остаются.
- **Машина 16 ГБ.** Тяжёлые прогоны — фоном через `nohup`, по одному, при
  свободной памяти от 25% (`memory_pressure -Q`). Два Chrome разом не запускать.
- **Каждый кадр живого прогона смотреть глазами до слов «готово».** Тесты и замер
  ловят не всё.
- **Работать в изолированной копии.** Коммиты по задачам, файлы перечислять
  явно, без `git add -A`.

### Задача 3: «слово порвано посреди»

**Причина:** у `.стрелка .бок` стоит `overflow-wrap:break-word` (card.py:1188).
Длинное слово не вылезает за колонку, а рвётся без дефиса, и `перелив` этого
не видит. Так было на постах 90, 96 и 98. Переносов с дефисом (`hyphens`) в
вёрстке нет, так что слово на двух строках — всегда поломка.

**Файлы:** `card.py` (`ЗАМЕР`, `проверить_композицию`),
`tests/test_проверки_кадра.py`.

**Даёт:** ключ `порвано: list[str]`; беду `"слово порвано посреди: <слова>"`.
Цикл ужатия в `слайд_вида` реагирует на неё сам.

            м = self._прочесть(срок)
            if м.get("id") == self.н:
                if "error" in м:
                    raise RuntimeError(f"{метод}: {м['error']}")
                return м.get("result", {})
            if "method" in м:
                self.события.append(м["method"])

    def ждать(self, событие: str) -> None:
        срок = time.time() + ОЖИДАНИЕ
        while событие not in self.события:
            м = self._прочесть(срок)
            if "method" in м:
                self.события.append(м["method"])
        self.события.clear()

    def открыть(self, путь: Path, ширина: int, высота: int, масштаб: float) -> None:
        self.позвать("Emulation.setDeviceMetricsOverride",
                     {"width": ширина, "height": высота,
                      "deviceScaleFactor": масштаб, "mobile": False})
        # Командная строка прячет полосы прокрутки только у снимка.
        self.позвать("Emulation.setScrollbarsHidden", {"hidden": масштаб != 1})
        self.события.clear()
        self.позвать("Page.navigate", {"url": f"file://{путь}"})
        self.ждать("Page.loadEventFired")
        self.позвать("Runtime.evaluate", {"expression": "document.fonts.ready.then(() => 1)",
                                          "awaitPromise": True})

    def замер(self) -> dict:
        срок = time.time() + 10
        while time.time() < срок:
            р = self.позвать("Runtime.evaluate", {
                "expression": "document.body && document.body.getAttribute('data-замер')",
                "returnByValue": True})
            значение = р.get("result", {}).get("value")
            if значение:
                return json.loads(значение)
            time.sleep(0.01)
        return {}

    def снимок(self, куда: Path) -> None:
        р = self.позвать("Page.captureScreenshot", {"format": "png"})
        Path(куда).write_bytes(base64.b64decode(р["data"]))


def _работа(дело):
    if not включён():
        return None
    try:
        with _замок:
            порт = _поднять()
            вкладка = getattr(_своё, "вкладка", None)
            if вкладка is None or getattr(_своё, "поколение", -1) != _браузер["поколение"]:
                вкладка = _Вкладка(порт)
                _своё.вкладка, _своё.поколение = вкладка, _браузер["поколение"]
            _браузер["в_работе"] += 1
    except Exception:                                        # noqa: BLE001
        return None
    try:
        return дело(вкладка)
    except Exception:                                        # noqa: BLE001
        _своё.вкладка = None
        return None
    finally:
        with _замок:
            _браузер["в_работе"] -= 1
            _браузер["последний"] = time.time()


def _в_файл(страница: str) -> Path:
    config.ВЫВОД.mkdir(parents=True, exist_ok=True)
    with tempfile.NamedTemporaryFile("w", suffix=".html", delete=False,
                                     dir=config.ВЫВОД, encoding="utf-8") as f:
        f.write(страница)
    return Path(f.name)


def замерить(страница_с_замером: str, ширина: int, высота: int) -> dict | None:
    """Координаты блоков. None или {} — мерить старым путём."""
    def дело(вкладка):
        путь = _в_файл(страница_с_замером)
        try:
            вкладка.открыть(путь, ширина, высота, 1)
            return вкладка.замер()
        finally:
            путь.unlink(missing_ok=True)
    return _работа(дело)


def снять(страница: str, ширина: int, высота: int, куда: Path) -> bool:
    """Снимок в полуторном масштабе, как у командной строки. False — снять старым путём."""
    def дело(вкладка):
        путь = _в_файл(страница)
        try:
            вкладка.открыть(путь, ширина, высота, 1.5)
            вкладка.снимок(куда)
            return True
        finally:
            путь.unlink(missing_ok=True)
    return bool(_работа(дело))


@atexit.register
def _на_выходе() -> None:
    with _замок:
        _погасить()
