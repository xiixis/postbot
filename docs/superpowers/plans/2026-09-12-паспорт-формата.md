# Паспорт формата — часть 1: ротация из готового и простой язык

> Спека: `docs/superpowers/specs/2026-09-12-разнообразие-каруселей-design.md`.
> Тесты: `python3 -m unittest discover -s tests -q` интерпретатором
> `/Users/xiix/4xSoft/yt-searcher/.venv/bin/python3`. Базовая линия: 238 OK.

**Цель.** Каждая карусель получает паспорт (тип, каркас, длина, дизайн,
оформление, кот), выбранный кодом без повторов недавнего. Дизайн и фон доходят
до обложки и финала. Голос канала требует простого языка.

**Ограничения.** `card.py` едет в облачную копию — `форматы.py` импортировать
только в `core`/`carousel`, не в `card`. Паспорт по умолчанию (`фирменный`,
`сетка`, кот) обязан давать кадры, совпадающие с эталоном поста 96. Работа в
копии `EnterWorktree`, коммит после зелёного набора.

## Задачи

1. **`форматы.py` + `tests/test_форматы.py`.**
   `ТИПЫ` (пока одна `обычная`: вес 2.4, кадров `[8, 12]`, кот, пять каркасов),
   `ДИЗАЙНЫ_ОК = ["фирменный"]`, `ОФОРМЛЕНИЯ_ОК` — все, кроме `инверсии`.
   `подобрать(история, случай) -> dict` — чистая функция: исключает пары
   тип+каркас двух прошлых паспортов и пары дизайн+оформление пяти прошлых;
   вес пары = вес типа / число его пар среди кандидатов, чтобы тип с пятью
   каркасами не забивал тип с одним. `следующий(куда)` берёт историю из
   `конвейер.настройки(куда)["форматы"]` и дописывает туда паспорт (последние 5).
   Тесты: нет повтора каркаса двух прошлых и вида пяти прошлых; при исчерпании
   кандидатов берётся любой; распределение весов на тысяче прогонов.

2. **Обложка и финал в дизайне и фоне.** `card.слайд_обложка` и
   `card.слайд_финал` получают `дизайн="фирменный", оформление="сетка"`;
   к их CSS добавляются `_дизайн(дизайн, д)` и стили `_оформление`, слой
   панели — в нутро. В CSS дизайнов `швейцарский`, `брутальный`,
   `редакционный`, `терминал` в первый список шрифтовых селекторов добавляется
   `h1`. Эталон поста 96 обязан пройти без изменений.

3. **`carousel.нарисовать` по паспорту.** `к.get("паспорт")` даёт дизайн,
   оформление и кота; обложка, середина и финал получают одно и то же. При
   `кот: false` середина рисуется без кота. `позы_слайдов` учитывает то же.
   Тест: подмена `card.слайд_*` ловит переданные дизайн и оформление.

4. **Сценарий по паспорту и простой язык.** `carousel.сочинить(...,
   паспорт=None)`: при паспорте вместо списка каркасов — блок «ФОРМАТ ЭТОЙ
   КАРУСЕЛИ» с выбранным каркасом и числом кадров; после ответа модели
   `к.каркас = паспорт["каркас"]`. Блок `ПРОСТО` в системной подсказке после
   `РЕЗЧЕ`. В `writer.ГОЛОС` — пункты про новичка, ребёнка и взрослого.
   Тест: подсказка содержит выбранный каркас и `ПРОСТО`, не содержит списка
   каркасов.

5. **`core.эскиз` выдаёт паспорт.** `форматы.следующий(площадка)`; для рерайта
   паспорт задаёт только вид (`каркас: ""`, `кадров: None`). Паспорт кладётся в
   `поля["carousel"]["паспорт"]`; `переписать` его сохраняет.

6. **Лист образцов для владельца.** Пост 96 в каждом дизайне на трёх фонах —
   одним листом, артефактом. Одобренные связки вписываются в `ДИЗАЙНЫ_ОК` /
   `ОФОРМЛЕНИЯ_ОК` отдельным коммитом.

7. **Свести и выкатить.** Весь набор, ревизия, `tools_vercel.py`, слияние по
   скилу «завершение-работы», перезапуск бота (проверив `jobs.в_работе()`),
   выкладка Vercel.
