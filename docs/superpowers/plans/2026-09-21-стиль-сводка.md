# Стиль «сводка»: карточка новости со снимком

> **Для исполнителя:** задачи идут по порядку, каждая заканчивается проверкой, вывод которой видно глазами. Шаги отмечать `- [x]` по мере выполнения.

**Цель:** завести стиль `postbot/Style/сводка/` по референсу @whygolding — светлая карточка, тёмная плашка-рубрика, заголовок, серый абзац и снимок продукта в каждом кадре — и выпустить в нём два поста: дайджест девяти событий ИИ и инструкцию для памяти Claude.

**Устройство:** отдельная папка стиля со своим `рисовать.py` (как у «до-после» и «подборка-сайтов»), а не новый дизайн внутри `card.py`: у кадра другая структура — карточка в карточке, обязательный снимок на 38% высоты и пара кнопок внизу, чего в вёрстках `card.py` нет. Снимки сайтов снимаются `снять.mjs` через playwright-core.

**Инструменты:** Python 3.12 из `yt-searcher/.venv`, Pillow, безголовый Chrome через `postbot/браузер.py`, node + playwright-core для снимков сайтов.

## Общие ограничения

- Кадр **1620×2160** (`стиль.W`, `стиль.H`), на стол уходит JPG 1080×1440 — как у всех стилей.
- Логотип на каждом кадре, включая запасные обложки (`стиль.знак_и_полоса`).
- Суммы только в `$`. Хештегов 5–8. Язык вслух не называть.
- Тексты простым языком, понятным новичку.
- Ничего из почерка автора: ни его ника, ни аватара, ни кнопки «Відправ друзям», ни финала с его телеграмом.
- Каждая правка коммитится отдельно; `git add` перечисляет файлы, `git add -A` запрещён.
- Отрисовка — одна за раз, фоном (`nohup ... &`), на машине 16 ГБ.
