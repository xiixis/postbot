# Конвейер v2, этап 1: приёмка досок холста — план выполнения

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans (или
> subagent-driven-development). Шаги — чекбоксы `- [ ]`. Родительский план:
> `2026-09-24-конвейер-карусели-v2.md`, раздел «Этап 1».

**Цель.** Одна команда по холсту выдаёт текстом «годен» или список бед с номерами досок;
картинки смотрятся только в конце, одним листом.

**Устройство.** Три проверки от дешёвой к дорогой: 1) по разметке без браузера — сколько
строк займёт крупный текст и на что он налезет; 2) в Chrome — общий замер запаса
`стиль.ЗАПАС_JS` на верхних блоках доски плюс зона кнопок TikTok; 3) по снимку —
`замер.py`. Итог в форме отчёта `приёмка.py` (`годен` / `брак: №N: …`).

**Стек.** Python 3.14 из `.venv`, прогретый Chrome (`браузер.py`), Pillow, numpy, unittest.

## Общие ограничения

- Доска холста — 1080×1440 CSS px, снимок ×1,5 = 1620×2160.
- Запас между блоками: правило владельца «40 px на кадре 1620» = 26,7 px доски; порог
  **26** (на принятых кадрах «пар» рубрика над категорией стоит ровно на 26 — разница
  меньше пикселя доски, на телефоне её нет).
- От края: 100 px кадра 1620 = **67** px доски. Кот может уходить за край; блок с
  `data-вылет` (лента «плёнка») — тоже.
- Зона кнопок TikTok: правее **900** px в полосе y **720–1190** (ниже середины, выше знака).
  Кот — брак, если его правый край дальше **920** (900 со слов владельца + 20 допуска:
  кот финала «пар» принят с краем 907). Любой другой блок — если он **начинается**
  правее 900. Сноска внизу справа (y ≥ 1191) допустима — память `зона-кнопок-тикток`.
- Фон, сетка и сцена во весь кадр (площадь ≥ 90% доски или `pointer-events: none`) — не
  блоки, их не судим.
- Замер по снимку (контраст, акцент, чернила) — **замечания**; брак из него только
  «контент заходит на знак». Принятые владельцем кадры не держат норму акцента 4–6%, и
  если бы это был брак, приёмка не пропустила бы ни одного холста.
- Картинки в разговор не читать; лист — один раз в конце.
- Одна тяжёлая задача за раз: Chrome один, снимки последовательно.

### Задача 2. Замер разметки в Chrome: `по_разметке`

**Файлы:** `Style/стиль.py` (`ЗАПАС_JS`), `Style/приёмка_досок.py`, тесты.

**Даёт:** `ЗАПАС, КРАЙ, КНОПКИ_X, ДОПУСК_КОТА, ЗОНА_ВЕРХ, ЗОНА_НИЗ` и
`по_разметке(папка, файл) -> list[str]`.
Сообщения: `впритык: <кто> ↔ <кто> <N> px`, `у края: <кто> <л>–<п>`,
`под кнопками TikTok: <кто> <л>–<п>`, `страница: …`.

Изменения `ЗАПАС_JS` (обратно совместимы — прежние вызовы `запас_кадра('…')` дают то же):
- сигнатура `запас_кадра(селекторы, запас = 40, край = 100)`;
- кот — класс `кот` **или** атрибут `data-кот`;
- `data-вылет` освобождает блок от проверки края;
- видимый блок с поворотом (`transform` с ненулевыми `b`/`c`) мерится горизонтальными
  срезами по 6 px его настоящего контура, а не описанным прямоугольником: у повёрнутой на
  7° ленты шириной 1240 рамка выше контура на ~150 px.

JS доски: верхние дети `x-dc > div`, кроме фона, получают `data-блок`; зона кнопок
считается там же; итог — `data-замер` = `{шрифты, зона, тесно, край}`.

- [ ] Тесты (Chrome) на битых эталонах: кот у края (финал «пар» 3b4e57c) → «под кнопками»;
      «Отменено» за краем (a602efa) → «у края»; вывод под плашкой (кадр 4) → «впритык»;
      кот вплотную к списку финала → «впритык».
- [ ] Тест: повёрнутая лента не даёт «впритык» с блоком, до которого по контуру > 26 px, а
      по описанному прямоугольнику меньше (синтетическая доска).
- [ ] Реализация; прогон; прежние тесты замера зелёные; коммит.

### Задача 4. Проверка по тексту без браузера: `по_тексту`

**Даёт:** `по_тексту(html: str) -> list[str]`, сообщение
`«<начало>» ≈<N> строк до <низ> px — налезет на «<сосед>» (верх <top>)`.

Разбор: верхние дети корневого `div` доски; для блока с одним текстом (только `span`/`br`
внутри), кеглем ≥ 56, известными `left`, `top`, `width` — жадный перенос по словам, ширина
знака: Onest 800 — 0,56 em, Golos — 0,5 em, Oswald — 0,42 em, прочие — 0,55 em;
высота = строки × кегль × `line-height`. Сосед — верхний блок с `top` ниже верха этого
блока, пересекающийся по горизонтали; беда, если оценённый низ ниже верха соседа.

- [ ] Тест: годные эталоны → пусто.
- [ ] Тест: битый «заголовок финала в 3 строки» → беда с «3 строк» и соседом-списком.
- [ ] Тест: «подпись обложки налезла на заголовок» (сдвиг `top`) → беда.
- [ ] Реализация, прогон, коммит.

### Задача 5. Замер снимка, отчёт, лист, команда

**Файлы:** `Style/замер.py` (`беды(д) -> list[str]`, `карусель` через неё), `Style/приёмка_досок.py`.

**Даёт:** `по_снимку(путь) -> tuple[list[str], list[str]]` (брак, замечания);
`проверить(холст, снимки=True) -> dict` — отчёт вида `приёмка.py` (`годен`, `кадры`:
`номер`, `вид`, `брак`, `замечания`, `ужато`) плюс `лист` (путь); `доложить(холст,
снимки=True) -> dict` печатает; CLI `python3 Style/приёмка_досок.py <холст>
[--без-снимка]`, код выхода 1 при браке.

`--без-снимка` — только проверка по тексту, без Chrome (как записано в плане v2).
