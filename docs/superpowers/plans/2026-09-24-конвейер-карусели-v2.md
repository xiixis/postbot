# Конвейер карусели v2: дешевле и с первого-второго раза

> Сессия, которая это открыла: перед работой взять скилы `writing-plans` (развернуть текущий
> этап в мелкие задачи с тестами) и `executing-plans`. Работать в изолированной копии
> (`cd ~/4xSoft/postbot` → `EnterWorktree`). **Один этап — одна сессия, потом `/clear`.**

**Цель.** Референс на входе — готовый качественный холст на выходе, за 1–2 круга правок
вместо 5, и примерно втрое дешевле по лимиту.

**Замысел.** Гибрид трёх вариантов, разобранных 24.09.2026: сперва машинная приёмка на
стилях (на ней стоит всё остальное), потом дешёвые агенты для механики, потом пост как
данные и каталог обложек. Уборка мёртвого кода — отдельным этапом, со списком на
утверждение владельцу.

## Почему так: замеры 24.09.2026

Сессия `019d021b` (два рерайта, 5 кругов правок владельца):

| Что | Число |
|---|---|
| запросов к модели | 614 |
| прочитано контекста | 249 млн токенов, пик 742 тыс. за запрос |
| картинок в контексте | 50 → ≈59 млн (24% сессии): кадр ≈4 тыс. токенов и живёт до конца |
| скилов целиком | 3 → ≈13 млн; один `hallmark` — 16,6 тыс. токенов, 8,6 млн |
| вызовов инструментов | 474, из них **248 (52%) — круг «правка → пересборка → снимок → смотрю»** |
| доля недели | сессия = 5,8% недельного расхода ≈ 3 п.п. лимита (неделя была на 51%) |

Лимит недели в основном ест разработка (четыре сессии — 62%), не посты. Но круг правок —
это ещё и время: половина кругов была машинной (наложение текста, кот под кнопками
TikTok), её ловит код; вторая половина — вкус (обложки), её сокращает каталог макетов.

**Что уже есть и работает только для постов бота (`card.py`), а стили `Style/*` идут мимо:**
- `предполёт.py` — брак по тексту до отрисовки;
- `приёмка.py` — журнал брака во время отрисовки, вердикт «годен / брак»;
- `tools_лист.py` + `лист.py` — лист кадров с обведённым браком;
- `Style/замер.py` — контраст, акцент, чернила, крупная строка, перепад;
- `Style/стиль.py` → `ЗАПАС_JS` / `запас_кадра()` — наложения блоков («тесно») и отступ от
  краёв («край»); сейчас его зовёт только старый `пары/рисовать.py`, доски холста — нет.

## Правила владельца, выученные 24.09 (должны стать проверками)

- Зачёркивание — **толстое и красное** (`#FF3B30`, черта-блок ~11% кегля с наклоном,
  `пары/категории.py: зачёркнуто()`), не `line-through` и не лаймом.
- Где уместен штамп «Отменено» поверх суммы — он **вместо** зачёркивания, сумма прячется
  («создаётся тайна»).
- **Зона кнопок TikTok:** справа примерно от 900 px и ниже середины кадра 1080×1440 ничего
  важного (кот, плашки). Память `зона-кнопок-тикток`.
- Важное выше 1105 px, логотип на 1191 (`дизайн_холст.НИЗ_СОДЕРЖИМОГО`, `ЗНАК_ВЕРХ`).
- Подпись до 80 знаков без хештегов, хештегов 6–8, название до 90 (`Style/выпуск.py`).
- В постах-подборках **не писать про тарифы** (сколько дней бесплатно, водяные знаки).
- Владельцу — только ссылка на холст, листы кадров картинками не присылать.
- Правки, сделанные владельцем руками на холсте, переносить в код (иначе пересборка их сотрёт).

**Файлы:**

- перенести из scratchpad в репозиторий `Style/снять_доски.py` (снимает **все** доски

  scratchpad сессии `019d021b` (`снять-доски.py`) — он временный, при потере написать заново

**Проверки (в порядке дешевизны):**

4. Итог в формате `приёмка.py` (`годен` / `брак: №N: …`), чтобы показывать одинаково.

**Встроить:** вызов после `дизайн_холст.собрать()` в `пары/категории.py` и
`сервисы/карточка.py`; флаг `--без-снимка` для быстрой проверки только по тексту.

**Результат:** картинки и возня с файлами уходят из главной сессии; главная (Opus) держит

## Этап 3. Пост как данные и каталог обложек

**Результат:** после «рисовать» холст собирается одной командой; обложка выбирается из
проверенных макетов, а не изобретается заново.

- **Каталог обложек** `Style/обложки.py`: вынести готовые макеты в функции с одним
  контрактом `(пост, ресурсы) → html`: чек-с-ценами, замена (пары колонками), списание со
  штампом, режиссёр-сцена, превращение, плёнка, девятка, дыра, веер (последние — из
  `подборка-сайтов/холст.py`). В каждой — какие поля поста нужны и какой крючок из
  `Style/КРЮЧКИ.md` она реализует.
- **Одна команда** `Style/карусель.py <пост.json>`: снабжение → сборка → приёмка → холст →
  ссылка. Без автопочинки: брак возвращается списком.
- Автопочинку (текст короче → другая вёрстка → убрать кадр, как лестница в
  `конвейер-карусели`) добавлять последней, когда наберётся статистика брака.

**Скилы:** `brainstorming` (контракт каталога), `writing-plans`, `test-driven-development`,
`визуал-слайдов`, из `hallmark` **только** `references/structure.md` и
`references/anti-patterns.md`.

## Правила сессии (экономия, действует с этапа 1)

1. Одна карусель или один этап — одна сессия, в конце `/clear`.
2. Скилы брать частями: `hallmark` целиком не грузить.
3. Картинки: лист — да; отдельный кадр крупно — только если приёмка указала на него.
4. Правки владельца с холста забирать в файл (`Artifact read` с `out_dir`) и сравнивать
   `diff` в терминале; целые `.dc.html` в разговор не читать.
5. Снимать только изменённые доски, не все девять.
6. Параллельные форки одной задачи не запускать (замер 14.09: два форка — 252 млн).
