# Конвейер v2, этап 3: каталог запасных обложек и одна команда сборки

Родитель: `docs/superpowers/plans/2026-09-24-конвейер-карусели-v2.md`, этап 3.
Решения владельца 24.09.2026: главная обложка — по референсу (как сейчас), две запасные — из
каталога; запасные — в теме стиля поста; команда — скрипт плюс готовые параметры выкладки
холста (выкладывает главная сессия одним вызовом). Остальное владелец отдал на решение
(«подумай, как лучше»). Работа — внутренний механизм для терминала Claude Code; как это
выглядит в боте, решается позже.

## Зачем

Запасные обложки изобретались заново на каждом посте и чаще всего уходили в круг правок
(24.09: «чек», «замена», «списание», «превращение», «плёнка» — каждая по два-три круга). Каталог
даёт готовые макеты, которые уже проходят приёмку досок в теме любого подключённого стиля.

## Что меняется против плана v2

- **Один макет «сцена» вместо пяти сценовых** (чек, режиссёр, девятка, дыра, веер). Сцены
  нарисованы под конкретный пост — цены на чеке, хлопушка, цифра 9 — и повторять их нельзя
  (правило 9). Переиспользуемо только устройство «текст в пустом месте сцены»; оно и идёт в
  каталог, а сама сцена каждый раз новая.
- **«Число» — в каталог.** В коде это самая частая запасная (7 стилей), в плане её не было.
- **«Проверенный» — доказуемо.** Тест собирает каждый макет в теме каждого подключённого
  стиля и прогоняет приёмку досок; всё должно быть годно.

## Устройство

### 1. Карточка сцены — `~/4xSoft/.claude/маскот/сцены/<сцена>.json`

```json
{"тёмная": false, "пусто": [80, 90, 560, 900], "кот": [610, 620, 1010, 1300]}
```

Координаты доски 1080×1440: `пусто` — прямоугольник под текст, `кот` — рамка кота на картинке.
Карточку пишет снабженец, когда кладёт сцену (он видит картинку). Зачем:
- макет «сцена» ставит текст в `пусто` и выбирает цвет текста по `тёмная`;
- в доску со сценой встаёт невидимый блок `data-кот` по рамке `кот` — **приёмка досок видит кота
  внутри картинки**. Это закрывает слепое пятно, из-за которого 24.09 подпись легла на ухо кота
  при вердикте «годен». Тот же блок ставит и стиль в свою главную обложку со сценой
  (`обложки.кот_сцены(карточка)`).

### 2. Каталог — `Style/обложки.py`

```python
@dataclass(frozen=True)
class Тема:            # объявляет стиль: ТЕМА = обложки.Тема(...)
    фон: str           # CSS background доски целиком
    тёмная: bool
    чернила: str; второй: str; тихий: str        # цвета текста
    акцент: str; на_акценте: str                  # лайм и текст по нему
    карточка: str; рамка: str                     # подложка карточек и тонкая рамка
    крупный: str; текст: str                      # CSS шрифтов заголовка и подписи
    край: int = 80

@dataclass(frozen=True)
class Макет:
    рисовать: Callable[[dict, Тема, dict], str]   # (поля обложки, тема, данные) → тело доски
    поля: tuple[str, ...]                          # обязательные поля обложки в посте
    данные: tuple[str, ...]                        # что нужно из поста: значки, пары, сцена
    крючок: str                                    # какой крючок из КРЮЧКИ.md реализует

МАКЕТЫ: dict[str, Макет]    # замена, списание, превращение, плёнка, число, сцена
```

Вспомогательное: `проверить(имя, обложка, данные) -> list[str]` (чего не хватает),
`файлы(запасные) -> list[Path]` (позы кота и сцены, которые положить рядом с досками),
`кот_сцены(карточка) -> str` (невидимый блок кота), `низ(тема) -> str` (логотип).

Макеты вынимаются из рисовальщиков, где они приняты: «замена», «списание» — `пары/категории.py`;
«превращение», «плёнка» — `сервисы/карточка.py`; «число» — `светлый-разбор/главы.py` (кот
переносится из колонки кнопок TikTok влево); «сцена» — по образцу обложек «чек» и «режиссёр».
Цвета и шрифты — только из темы, координаты — от `тема.край`.

### 3. Пост

```json
"главная": "обложка",                  // или имя запасной, если владелец выбрал её
"обложка": {...},                       // своя, по референсу — рисует стиль, как сейчас
"запасные": {"списание": {...}, "замена": {...}},
"холст": "https://claude.ai/artifact/…" // после первой выкладки
```

Подключаются сначала два стиля, где запасные уже живут и приняты: «пары» (`категории.py`) и
«сервисы» (`карточка.py`). Их посты 24.09 переводятся на `"запасные"`; снимки запасных до и
после должны совпасть (сверка пикселями). «Подборка сайтов» и «светлый разбор» подключаются при
следующем посте в них. Старые стили — этап 4.

### 4. Команда — `Style/карусель.py <стиль>/посты/<пост>.json [--без-снимка]`

1. Рисовальщик — `<стиль>/<вид>.py` по полю `"вид"`; нет — список кандидатов и стоп.
2. Снабжение: проходит пост и сверяет файлы — `"файл"` → `<стиль>/значки/`, `"поза"` →
   `assets/mascot/позы/`, `"сцена"` → `маскот/сцены/<сцена>.jpg` и карточка `.json` (или путь
   `картинки/…` у старых постов). Чего нет — список «для снабженца» и выход с кодом 2.
3. Обложки: запасных ровно две, разные, есть в каталоге, поля на месте
   (`обложки.проверить`). Та же пара запасных, что у прошлого поста стиля, — предупреждение, не
   стоп (правило 9 про ленту профиля, а запасные в ленту попадают, только если их выбрали).
4. Сборка рисовальщиком отдельным процессом; он сам печатает приёмку досок.
5. Итог: вердикт, путь к листу и параметры выкладки — `url` из поля `"холст"` (или «новый холст:
   quickstart intent design»), `root`, `file_path: project/canvas.json`. Код выхода 1 при браке.

Автопочинки нет: брак возвращается списком.
