## 1. Mixkit — звуки, музыка, вертикальное видео

**Что брать.**
- Звуки: разделы `whoosh`, `transition`, `click`, `pop`, `swoosh`, `notification`, `typing`
  (`mixkit.co/free-sound-effects/<раздел>/`). Это пополнение `public/sfx/lib`: сейчас там 19 файлов Pixabay.
- Вертикальное видео 1080×1920: `mixkit.co/free-stock-video/vertical/`, около 2100 клипов. Подходит
  для фона под карточками и для перебивок.
- Музыка годится для подложки, но с оговорками, они ниже.

**Лицензия.** [прочитано, текст лицензий снят с `mixkit.co/license/modal/<вид>/`]
- Звуки (Sound Effects Free): коммерция и соцсети разрешены, автора указывать не надо. Нельзя
  раздавать сами файлы как сток или в составе шаблона и нельзя регистрировать их в Content ID.
- Видео (Stock Video Free): то же самое, автора указывать не надо. **Но у части клипов лицензия
  Restricted, только для личного:** на канале бизнеса и в рекламе их ставить нельзя. Вид лицензии
  написан в разметке страницы клипа (`"license":"https://mixkit.co/license/#videoFree"`), его можно
  проверить скриптом.
- Музыка (Stock Music Free): соцсети и YouTube разрешены. Нельзя ремиксовать и делать из неё трек
  без картинки. Сам Mixkit пишет: «если пришла претензия, перешлите на team@mixkit.co», то есть
  претензии Content ID возможны. Наш `tools/loop.py` удлиняет трек склейкой. Внутри ролика это
  правка под конечный продукт, но готовую длинную склейку отдельным файлом наружу не отдавать.

**Как скачать.** [скачано] Вход не нужен, `robots.txt` разрешает всё (закрыт только CCBot).
Номер звука берётся со страницы раздела, из атрибута `data-audio-player-item-id-value`.

```sh
# полный WAV (кнопка Download отдаёт то же самое); -preview.mp3 — урезанное MP3
curl -sLo public/sfx/mixkit/1489-air-woosh.wav https://assets.mixkit.co/active_storage/sfx/1489/1489.wav
# номера и названия всех звуков раздела
curl -sL -A Mozilla/5.0 https://mixkit.co/free-sound-effects/whoosh/ | grep -o 'item-id-value="[0-9]*"'
# видео: качество 360 / 720 / 1080 (2160 закрыто, 403); 1080 весит десятки МБ (у клипа 1164 — 72 МБ)
curl -sLo bg.mp4 https://assets.mixkit.co/videos/1164/1164-1080.mp4
```

Проверено: `1489.wav` — 614 КБ, WAVE, PCM 24 бит, 44,1 кГц, стерео, 2,32 с. У `/sfx/<id>/<id>.mp3`
ответ 403: полный файл только в WAV. В репозиторий класть сжатым:
`ffmpeg -i x.wav -c:a libmp3lame -q:a 2 x.mp3`.

**Как встроить.** Звук ставится не в HyperFrames, а в `tools/sound.py`, как сейчас Pixabay: строка
`["mixkit/1489-air-woosh.mp3", "<ид сцены>", сдвиг, громкость]`. Происхождение записать в
`public/sfx/mixkit/CREDITS.md`: номер, название, ссылка, «Mixkit Sound Effects Free License».
Видео на фон в HyperFrames:

```html
<video src="assets/bg/1164.mp4" data-start="0" data-duration="6" data-track-index="0" muted playsinline
       style="position:absolute;inset:0;width:100%;height:100%;object-fit:cover"></video>
```

**Где не годится.** Генерация «Generate with AI» на сайте — это не сток, у неё свои условия. Клипы
Restricted. Музыка в ролик, который пойдёт в ТВ или в игру.

## 2. FreshLUTs — цветовые таблицы `.cube`

**Что это.** Сборник бесплатных LUT, которые загружают пользователи, около 3 млн скачиваний. Формат —
`.cube` (3D-таблица).

**Лицензия.** CC0, по условиям сайта (`/termsandconditions`): можно в коммерции, автора указывать не
надо. [прочитано]

**Как скачать.** **Только с аккаунтом.** На странице LUT кнопка «Download LUT» ведёт на
`/users/sign_up` (проверено на `/luts/591`). Ни API, ни MCP нет. Скачивание я не обходил: брать
руками после входа, класть в `public/luts/`.

Чтобы всё же проверить команду, взял публичную таблицу HeyGen из каталога `media-use`
(`https://static.heygen.ai/luts/teal-orange-blockbuster.cube`). [скачано] Это ASCII `.cube` на
35 941 строку. Результат замера: серый #D0B090 стал #F7BF86, тёмный #202020 стал #02131B, то есть
тени ушли в бирюзу, света потеплели.

```sh
# весь ролик целиком
ffmpeg -i in.mp4 -vf "lut3d=file=look.cube:interp=tetrahedral,format=yuv420p" \
  -c:v libx264 -crf 17 -preset slow -c:a copy -movflags +faststart out.mp4
# на половину силы
ffmpeg -i in.mp4 -vf "split[a][b];[b]lut3d=look.cube[g];[a][g]blend=all_expr='A*0.5+B*0.5',format=yuv420p" ... out.mp4
```

**В HyperFrames — только на конкретный клип**, без перекодирования всего ролика. [прочитано,
`media-use/references/grading.md`] Делается атрибутом `data-color-grading` у `<video>` или `<img>`:
`{"intensity":1,"lut":{"src":".media/luts/x.cube","intensity":0.85}}`. Силу можно вести по времени
твином CSS-переменной `--hf-color-grading-lut-intensity` от 0 до 1. Таблицу заводить через
`npx hyperframes media-use resolve --type lut --from x.cube --project .`: там она проверяется.
Сам `.cube` в контекст не читать, это десятки тысяч строк чисел.

**Честно о пользе.** Наш ролик — графика в цветах бренда, а LUT сдвигает все цвета. Пропущенный
через LUT ролик целиком испортит лайм #C7E24B и графит. Поэтому **на готовый mp4 LUT не ставить.**
Польза есть в двух местах:
1. Стоковое видео Mixkit на фоне: тёплое или холодное видео притянуть к оливе и графиту. Обработать
   один раз ffmpeg до сборки или задать `data-color-grading` на этом `<video>`.
2. Живые снимки и съёмка: экран телефона, видео с камеры.

Снимки экрана интерфейсов не трогать: цвета чужого продукта узнаются, и их правка выглядит как
ошибка. Вывод: FreshLUTs — по случаю и руками, в проект ставить нечего.

## 3. LottieFiles — готовые векторные анимации

**Что брать.** Мелкие акценты и значки в движении: галочка «готово», загрузка, стрелки, сердечко,
подписка и колокольчик, конфетти (если владелец его вернёт), курсор и клик, переходы-формы. Кот
бренда трёхмерный, поэтому персонажи из Lottie нам не подходят. Ещё есть официальный блок
`npx hyperframes add lottie-character-walk` с примером «персонаж ходит и показывает».

**Лицензия.** [прочитано: выдержки из Lottie Simple License по поиску; сама страница
`lottiefiles.com/page/license` отвечает автоматике 403] Бесплатные публичные анимации идут по
Lottie Simple License: можно в коммерции и с правками, автора указывать не надо. Нельзя раздавать
файлы отдельно, перепродавать и собирать из них свой сток. Платные анимации (Premium, IconScout)
идут по другой лицензии. API поля лицензии не отдаёт, поэтому **перед выпуском открыть страницу
анимации глазами** и убедиться, что она бесплатная.

**Как скачать.**
- Сайт закрыт от скриптов проверкой Cloudflare («Just a moment…», 403). Я её не обходил.
- **Публичный GraphQL** `https://graphql.lottiefiles.com/2022-08` отвечает без входа. [скачано]
  Поиск возвращает прямые ссылки `jsonUrl` и `lottieUrl` на `assets-v2.lottiefiles.com`:

```sh
curl -s -X POST https://graphql.lottiefiles.com/2022-08 -H 'content-type: application/json' \
  -d '{"query":"{ searchPublicAnimations(query:\"success check\", first:6){ edges{ node{ id name url jsonUrl lottieUrl createdBy{ username } } } } }"}'
curl -so public/lottie/success-check.json https://assets-v2.lottiefiles.com/a/09abb35e-d772-41b4-a920-8bb10d2016d8/J2DJhBJPmT.json
```

  Проверено: JSON 52 КБ, Lottie 5.7.0, 60 к/с, 151 кадр (2,52 с), 1080×1080, 5 слоёв, без картинок
  и без выражений. `.lottie` весит 3,2 КБ: это zip с `manifest.json` и `a/Main Scene.json`.
- **Официальный MCP** `claude mcp add --transport http lottiefiles https://mcp.lottiefiles.com/mcp`
  [прочитано]: вход через OAuth с аккаунтом LottieFiles, внутри тот же GraphQL (4 инструмента).
  Второй, `@lottiefiles/creator-mcp`, правит анимации в редакторе Creator. Нам хватает запроса
  `curl` выше.

**Цвета бренда.** У анимаций чужая палитра: в образце 9 цветов, от #00FFC8 до #FF005D. Перекраска
делается скриптом `tools/lottie-tools.py` [скачано, 34 замены]:

```sh
python3 lottie-tools.py recolor in.json out.json '#00FFC8=#C7E24B' '#F5B401=#56690C'
python3 lottie-tools.py shift   out.json out-at2s.json 2.0   # вшить начало на 2-й секунде
```

**Как встроить в HyperFrames.** [исходник + lint] Адаптер `lottie` сам перематывает каждый плеер из
`window.__hfLottie` на время ролика через `goToAndStop`. Свой `onUpdate` писать не надо, да и нельзя:
адаптер всё равно найдёт плеер через `lottie.getRegisteredAnimations()` и перемотает его поверх.
**Ловушка:** время Lottie отсчитывается от начала ближайшей `[data-composition-id]`, а не от сцены.
В нашем однокорневом `index.html` анимация, вставленная в сцену на 30-й секунде, проиграется в
первые 2,5 секунды ролика, и в сцене останется последний кадр. Есть два способа:

1. **Вшить начало в файл** (`lottie-tools.py shift`): к `st`, `ip` и `op` слоёв прибавляется сдвиг.
   Подходит к нашему устройству «одна страница, один таймлайн».
2. **Сделать отдельную под-композицию** с `data-start`: её время адаптер берёт сам.

```html
<!-- в <head> рядом с gsap: плеер без выражений (eval), только SVG, 168 КБ -->
<script src="assets/lottie_light.min.js"></script>
...
<div id="check-a" class="lot" style="position:absolute;left:290px;top:800px;width:500px;height:500px"></div>
<script>
  const a = lottie.loadAnimation({ container: document.getElementById('check-a'), renderer: 'svg',
    loop: false, autoplay: false, path: 'assets/lottie/check-brand-at2s.json' });
  window.__hfLottie = window.__hfLottie || [];
  window.__hfLottie.push(a);
  // появление и уход — обычными твинами по контейнеру
  tl.to('#check-a', { opacity: 0, duration: 0.3 }, 3.6);
</script>
```

Под-композиции нужен свой `<script src="assets/lottie_light.min.js">` внутри `<template>`, иначе
lint выдаёт ошибку `missing_lottie_script` (проверено). Полный рабочий пример обоих способов лежит в
`hf-test/`: lint даёт 0 ошибок и 1 предупреждение `nested_structure_needs_subcomposition`, такое же,
как у r11. Рендером оба способа **не проверены**. Перед первым роликом снять
`npx hyperframes snapshot --at 1,2.5,4.5` и посмотреть, что галочка стоит там, где задумано.

**В Remotion** [прочитано]: `@remotion/lottie@4.0.482` (зависит от `lottie-web@^5`). Сдвиг даёт
`<Sequence from={кадр}>`, вшивать ничего не нужно:

```tsx
import { Lottie } from '@remotion/lottie';
import data from '../public/lottie/check-brand.json';
<Sequence from={60} durationInFrames={90}><Lottie animationData={data} loop={false} /></Sequence>
```

**Где не годится.** Карусели: там статичный кадр, проще SVG. Анимации с растровыми картинками
внутри (`assets[].p` с `data:image`): мыло на 1080. Файлы с выражениями After Effects: на
`lottie_light` они не играют, а полный `lottie.min.js` исполняет их через `eval`.

## 4. Phosphor Icons — значки

**Что брать.** 1512 значков в шести начертаниях: `thin`, `light`, `regular`, `bold`, `fill`,
`duotone` (проверено по папкам пакета). Для ролика лучше всего `bold` и `fill`: тонкие линии на
телефоне пропадают. `duotone` хорош для плашек: вторая заливка идёт с `opacity="0.2"`, её можно
перекрасить в оливу. Есть `cat`, `terminal-window`, `rocket-launch`, `check-circle`, `sparkle`,
`cursor-click`, `bell` и всё обычное для интерфейсов. **Логотипов сервисов в наборе нет**: они
по-прежнему из `public/brand` и `theSVG`.

**Лицензия.** MIT, указывать автора в ролике не нужно. [прочитано в репозитории и npm]

**Как скачать.** [скачано] Аккаунт не нужен, официального MCP нет (есть сторонние, они не нужны):

```sh
npm i -D @phosphor-icons/core        # 2.1.1, MIT, 37 МБ на диске (каждый значок в 6 начертаниях)
# файлы: node_modules/@phosphor-icons/core/assets/<вес>/<имя>-<вес>.svg
# поиск по меткам: node -e "const {icons}=require('@phosphor-icons/core');console.log(icons.filter(i=>i.tags.includes('kitty')))"
# без установки, одним файлом:
curl -so check-circle-bold.svg https://cdn.jsdelivr.net/npm/@phosphor-icons/core@2.1.1/assets/bold/check-circle-bold.svg
```

Проверено: `terminal-window-bold.svg` весит 374 байта, `viewBox="0 0 256 256"` и `fill="currentColor"`.
`file` определяет SVG.

**Как встроить в HyperFrames.** Вставлять разметкой прямо в страницу, как это уже сделано со
значками в `scenes.js`. Цвет задаётся CSS `color`, движение — твинами по обёртке:

```js
import fs from 'node:fs';
const icon = (name, w = 'bold') => fs.readFileSync(
  `node_modules/@phosphor-icons/core/assets/${w}/${name}-${w}.svg`, 'utf8');
// в разметке: `<div class="ico" style="color:#C7E24B">${icon('terminal-window')}</div>`
tl.fromTo('.ico', { opacity: 0, scale: 0.6 }, { opacity: 1, scale: 1, duration: 0.5, ease: 'back.out(2)' }, 1.0);
```

В `hf-test/index.html` значок вставлен именно так, lint проходит.

**Ловушка для «рисования линией».** Значки Phosphor — залитые контуры, а не штрих. Если твинить
`stroke-dashoffset`, как в r11 у галочки, получится обводка контура, а не рисование. Для рисования
нужен набор со штрихом (Lucide, Tabler) или своя линия.

**Карусели.** Годится полностью. По памяти «значки в кадрах» картинку через `file://` Chrome молча не
рисует, а встроенный SVG рисует, поэтому вставлять разметкой. В Remotion то же самое, или пакет
`@phosphor-icons/react` (2.1.10).

## 5. React Bits — эффекты текста и фоны

**Что это.** 213 компонентов React (каждый в четырёх вариантах: JS или TS, CSS или Tailwind), ставятся
исходником через реестр shadcn. [скачано: `https://reactbits.dev/r/registry.json`, 852 записи]

**Лицензия.** MIT + Commons Clause [скачано: `LICENSE.md`]. Пользоваться можно, в том числе
коммерчески. Нельзя продавать и раздавать сами компоненты, «отдельно, в наборе или в виде порта».
Свой перенос на GSAP внутри закрытого репозитория для наших роликов разрешён. Выкладывать этот перенос
библиотекой наружу нельзя.

**Как достать.** Вход не нужен.
```sh
curl -s https://reactbits.dev/r/BlurText-JS-CSS.json      # исходник в поле files[].content
npx shadcn@latest add @react-bits/BlurText-TS-TW          # если ставить в React-проект
npx shadcn@latest mcp init --client claude                # «официальный» MCP: это MCP shadcn, своего у React Bits нет
```

**Главное: как есть в ролик не переносятся.** [скачано, разобраны исходники] Все эффекты крутятся
на часах браузера: `ShinyText` на `useAnimationFrame`, `DecryptedText` на `setInterval` и
`Math.random`, `Aurora` на `requestAnimationFrame` с `uTime`, `SplitText` через ScrollTrigger. При
покадровой перемотке это даёт мусор. Брать нужно **замысел и параметры** (кривые, задержки, цвета) и
переписывать твинами. Сам GSAP 3.15 в `reels` уже содержит `SplitText`, `ScrambleTextPlugin`,
`DrawSVGPlugin`, `MorphSVGPlugin` и `TextPlugin`: с 3.13 они бесплатные и лежат в `gsap/dist`.

| Эффект | Зачем нам | Как сделать в HyperFrames |
|---|---|---|
| **BlurText** | вход заголовка словами | `tl.fromTo(слова, {opacity:0, filter:'blur(14px)', y:40}, {opacity:1, filter:'blur(0px)', y:0, stagger:0.12})` — в `hf-test`. README велит не анимировать `blur()` напрямую: Chrome размывает ступенями. Для крупного текста лучше «перевод фокуса»: резкий и размытый слой со сменой прозрачности |
| **SplitText** | буквы и слова по очереди | разбивать на `<span>` при сборке строки, как уже сделано в r11. Плагин `SplitText` даёт то же, но только после `document.fonts.ready` |
| **CountUp / Counter** | цифры: «54 с», звёзды | уже есть в r11: твин `textContent` со `snap` |
| **ShinyText / GradientText** | блик по слову-крючку | `background:linear-gradient(...); -webkit-background-clip:text; background-size:200%`, твин `backgroundPosition` от `'100% 0'` до `'-100% 0'` |
| **DecryptedText / Shuffle** | «взлом» и раскрытие названия | `ScrambleTextPlugin` берёт `Math.random`, и вкладки рендера дадут разные кадры. Детерминированно так: при сборке на каждую букву 3–4 подставных символа по `rnd(seed)` из r11, и показывать их по очереди через `tl.set` |
| **TextType** | набор промпта | уже есть в r11: буквы с прозрачностью и мигающий курсор твином `repeat` |
| **TrueFocus** | фокус по словам фразы | резкий и размытый слой на каждом слове, по очереди |
| **SplitFlapText** | табло «было/стало», цифры | `rotationX` половинок карточки, `perspective` на обёртке |
| **StrokeText** | надпись рисуется контуром | `DrawSVGPlugin` по SVG-тексту, потом заливка |
| **GradualBlur / Noise** | — | не брать: README запрещает зерно, а размытие у краёв читается как плохое качество |
| **Aurora, Threads, LightRays, Grainient, SoftAurora** (WebGL на `ogl`) | живой фон в паузе | только через событие `hf-seek` (`adapters/three.md`): в обработчике `uTime = e.detail.time`, отрисовать один кадр. Для Remotion — `useCurrentFrame()/fps`. Тяжело для 16 ГБ при четырёх вкладках рендера, сначала проба |

Перенос «Shiny» без React и без часов:

```html
<span class="shine">бесплатно</span>
<style>.shine{background:linear-gradient(110deg,#C7E24B 40%,#F1F2EA 50%,#C7E24B 60%);background-size:250% 100%;
  background-position:100% 0;-webkit-background-clip:text;background-clip:text;color:transparent}</style>
<script>tl.fromTo('.shine', { backgroundPosition: '100% 0' }, { backgroundPosition: '-150% 0', duration: 1.2, ease: 'none' }, T);</script>
```

**Где не годится.** Карусели (там нет движения, а фон можно один раз снять в PNG). Всё, что
реагирует на курсор (`*Cursor`, `Magnet`, `ClickSpark`): в ролике курсора нет, курсор как причину
рисуем сами.
