# Ролики канала

Вертикальные ролики для Reels и TikTok. Собираются кодом в Remotion: кадр — это страница,
ролик — её состояния во времени. Мышь и монтажная программа не нужны.

## Что где лежит

| Путь | Что это |
|---|---|
| `src/Root.tsx` | список роликов: размер, длина, частота кадров |
| `src/claude-montage/` | ролик «Этот ролик никто не монтировал» |
| `src/claude-montage/tokens.ts` | цвета, шрифты, кегли, сетка времени и кривые движения |
| `public/claude-montage/` | крупный и общий планы, размытый фон, знак, пять треков |
| `public/sfx/` | короткие звуки |
| `tools/stills.mjs` | контрольные кадры одной сборкой |
| `tools/keys.py` | звуки клавиатуры, собранные кодом |
| `out/` | кадры и рендеры, в историю не идут |

Спека ролика: `../docs/superpowers/specs/2026-09-29-ролик-claude-монтаж-design.md`.

## Установка

Зависимости перечислены в `package.json`. На новой машине: `npm install` в этой папке.

На маке владельца `node_modules` — ссылка на уже установленный Remotion той же версии
в `yt-searcher/marco-pipeline/remotion-lab`. Так же постбот пользуется общим питоном из
`yt-searcher/.venv`. Ссылка в историю не идёт.

## Команды

Все из папки `reels`.

```
npm run list                                  # какие ролики есть
npm run stills -- ClaudeMontage 0 100 262     # кадры в out/ClaudeMontage/
npm run studio                                # смотреть и двигать в браузере
npx remotion render src/index.ts ClaudeMontage out/ролик.mp4 --codec=h264 --crf=15 --pixel-format=yuv420p --concurrency=2
```

Музыка выбирается настройкой `music`: `a`, `b`, `c`, `d`, `e` или `none`. Значение передаётся файлом:
`--props=out/props.json`, внутри `{ "music": "b" }`.

## Как делать следующий ролик

1. Сценарий владельцу: состояния, текст каждого, что движется. Рисовать до «да» нельзя.
2. Новая папка в `src/`, композиция в `Root.tsx`. Кривые движения и цвета брать из
   `tokens.ts`, а не подбирать заново.
3. Кадры каждого состояния и каждого перехода снять `stills` и посмотреть глазами.
4. Перед рендером проверить память: `sysctl vm.swapusage`. Рендер один, фоном.

## Правила, проверенные на деле

- Первый кадр — обложка: герой смотрит в камеру, заголовок крупно, движение с первой доли секунды.
  Тёмный размытый фон с одним текстом владелец счёл поводом пролистать.
- Одна картинка дважды за ролик не ставится: начало и развязка — разные планы.
- Повторяющийся звук собирается из нескольких разных и с неровным шагом (`tools/keys.py`).
- Состояние держится не меньше двух секунд. Тринадцать экранов за пятнадцать секунд
  владелец назвал хаосом.
- Один фон, одна манера движения, без отскоков.
- Текст не правее 900 px и не ниже 1500 px: там кнопки и подпись площадки.
- Поддельные рамки окон с тремя точками не рисовать.
- Слово Claude — терракотовое `#D97757`.
- Музыку модель не слышит. Темп и первый удар замеряются, а выбирает трек владелец.
