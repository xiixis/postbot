# Текст озвучки r13: абзацы, роли строк, манера

Голос «А-рассказчик» (Fish Audio s2.1-pro-free), весь текст одним запросом, манера одна на ролик:
`[calm, confident narrator]` — спокойный рассказ новости с лёгкой иронией, без скачков настроения.
Абзац кончается строкой с ролью «итог»: там пауза длиннее и интонация вниз. Сценарий — `voice/r13.json`.

| Абзац | Строка | Роль | Текст |
|---|---|---|---|
| 1. Новость | hook | заголовок | Илон Маск согласился: его Грок хуже, чем у конкурентов. |
| | post | строка | Разработчик выложил рейтинг нейросетей. |
| | views | итог | Больше семи миллионов просмотров. |
| 2. Ответ | musk | строка | А Маск ответил: «Точно. Пока что». |
| | look | итог | Смотри, кто где. |
| 3. Низ | bottom | строка | В самом низу отдельный ранг. |
| | google | строка | Его назвали просто: Гугл. |
| | gem | строка | Там все Джемини. |
| | f | итог | Им даже букву Эф пожалели. |
| 4. Середина | e | строка | Чуть выше Хайку, Мистраль и Немотрон. |
| | grok | строка | Грок самого Маска размазан посередине: от Си до Эй. |
| | a | итог | В Эй ещё Дипсик, Кими и прошлые Клоды. |
| 5. Вершина | s | строка | В Эс новый Фейбл от Антропик и Джи-пи-ти шесть Сол. |
| | ss | строка | Ещё выше Джи-пи-ти шесть Астра. |
| | top | итог | А на самой вершине только один. Клод Опус пять и пять. |
| 6. Шутка | fight | строка | Они бьются за трипл эс. |
| | siri | итог | А Сири всё ещё ищет ответ в интернете. |
| 7. Вывод | race | итог | Маск сказал «пока что». Значит, гонка не закончена. |
| 8. Вовлечение | q | вопрос | А ты на какой нейросети сидишь? |
| | com | строка | Пиши в комменты свой ранг. |
| | share | итог | И скинь другу, который до сих пор спрашивает погоду у Сири. |
| 9. Призыв | cta | призыв | Весь рейтинг одной картинкой лежит в нашем Телеграме. |
| | link | итог | Ссылка в профиле. Сохрани, чтобы не потерять! |

Почему так:
- Первая фраза — конфликт целиком (Маск признал, что его модель хуже), а не «вот рейтинг».
- Рейтинг идёт снизу вверх: ожидание вершины держит до 38-й секунды, бегунок рангов это показывает.
- Шутка про Siri стоит сразу после вершины: разрядка перед призывом, и она же даёт повод переслать.
- Призыв двойной: комментарий со своим рангом (вовлечение) и Telegram, где лежит картинка рейтинга.
- Чужие названия и буквы рангов написаны, как звучат. Распознавание на них спотыкается
  (сходство 0,43–0,8 у строк с названиями), поэтому эти строки слушает владелец.
