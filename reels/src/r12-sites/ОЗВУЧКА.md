# Озвучка ролика r12: текст по ролям

Весь текст одним запросом, манера `[calm, confident narrator]`, голос «А-рассказчик». Роль строки задаёт знак и паузу;
абзац кончается на строке «итог». Чужие названия написаны, как звучат; распознавание с подсказкой слышит их правильно
(Mixkit, FreshLUTs, LottieFiles, Phosphor, React Bits, Claude).
